What Mamut can tell

Servers decide what they reveal, and Fediverse software differs. Mamut only reports what a server actually says.

Software What’s detectable
Mastodon, Hometown Suspended, limited, moved, memorialized, and, from version 4.7, self-deleted.
Lemmy Banned (with end date), self-deleted.
Misskey, Sharkey Limited and moved. Suspended accounts look like accounts that never existed.
Everything else Whether the handle resolves. A resolving account may still be suspended.

The account’s home server decides whether it’s suspended overall. Other servers can restrict it independently, but only know accounts that have reached them, so “Not known here” is normal for smaller accounts.

Blocks between individual users are private, and no tool can see them.
